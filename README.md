# FileServer

A simple in-memory file server built with ASP.NET Core for uploading and downloading files via Base64.

## Features

### API Endpoints
| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/files` | Upload a file as Base64 |
| `POST` | `/api/files/upload` | Upload a file (multipart form) |
| `GET` | `/api/files/{id}` | Download a file by GUID |
| `GET` | `/api/files/list` | List all files with details |
| `GET` | `/api/files/stats` | Get memory usage statistics |
| `GET` | `/swagger` | Swagger UI (API documentation) |
| `GET` | `/hangfire` | Hangfire dashboard (public) |

### Upload (Base64)
- **Endpoint**: `POST /api/files`
- **Request body**: `{ "base64Content": "..." }`
- **Response**: `{ "id": "guid" }` with `201 Created`
- **GUID**: Generated by server

### Upload (File)
- **Endpoint**: `POST /api/files/upload`
- **Request**: `multipart/form-data` with `file` field
- **Response**: `{ "id": "guid" }` with `201 Created`
- **GUID**: Generated by server

### Download
- **Response**: File stream with auto-download behavior
- **Content-Type**: `application/octet-stream`
- **Filename**: GUID without extension (user can rename with correct extension if known)
- **Not found**: Returns `404` with descriptive message

### Stats
- **Response**: `{ "totalFiles": 42, "totalSizeBytes": 15728640, "totalSizeMB": 15.0 }`

### List Files
- **Response**: Array of file info objects
```json
[
  {
    "fileId": "guid",
    "createdAt": "2026-03-20T12:30:00",
    "timeUntilExpirationMinutes": 25,
    "fileSizeMB": 0.0125
  }
]
```

### Core Functionality
- **Storage**: In-memory database (non-persistent)
- **Public API**: No authentication required

### Background Jobs
- **Hangfire** cleanup job runs every `x` minutes
- Deletes files older than `y` minutes (based on **upload time**)
- Both `x` and `y` are configurable via `appsettings.json`
- **Dashboard**: Enabled at `/hangfire` (no authentication)

### Configuration (`appsettings.json`)
- Cleanup interval (`x` minutes)
- File expiration time (`y` minutes)
- Maximum file size threshold
- Timezone offset (hours, e.g., `-2`, `0`, `+3`)

### Error Handling
- **File not found**: Returns `404` with descriptive message
- **Invalid Base64**: Returns `400` with descriptive message
- **File too large**: Returns `400` if size exceeds configured threshold

### Deployment
- Docker support included

## Tech Stack
- C# / .NET
- ASP.NET Core
- Hangfire
- Swagger / OpenAPI
- Docker

## Getting Started

```bash
# Run locally
dotnet run

# Run with Docker
docker build -t fileserver .
docker run -p 8080:8080 fileserver
```

## Links (when running locally on port 8080)

- **Swagger UI**: http://localhost:8080/swagger
- **Hangfire Dashboard**: http://localhost:8080/hangfire

## Notes

> The download endpoint mimics existing file server behavior: opening the URL in a browser triggers an automatic download. The downloaded file may have no extension—set it manually (e.g., `.jpeg` for images).
